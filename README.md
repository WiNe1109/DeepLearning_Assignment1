# Single Layer Perceptron - Iris Dataset

This project implements a Single Layer Perceptron (SLP) for binary classification of the Iris dataset, focusing on **Setosa (0)** and **Versicolor (1)**. It is part of Assignment 1 for Machine Learning.

---

## Project Structure
- **PMM-TemplateSLP.xlsx** → Spreadsheet with manual SLP training and validation steps
- **slp_excel.py** → Python implementation of the perceptron using the Excel dataset
- **PowerPoint (7 slides)** → Presentation comparing spreadsheet and Python results

---


##Output
Accuracy Chart: Training vs Validation accuracy across epochs

Loss Chart: Training vs Validation log loss across epochs

Charts can be saved as .png images and inserted into the PowerPoint slides
